# c-programlama-örnekleri
bu depoda ,C programlama dilini öğrenme sürecimde yazdığım temel algoritmaları,ödevleri ve kod örneklerini topluyorum.
##Depo içeriği
bu proje altında şu konulara aitkod örnekleri yer almaktadır:
* **karar yapıları:** 'if-else' örnekleri ve akış diyagramı mantıkları.
* **döngüler:**'for' ve 'while' döngüsü çalışmaları.
* **matrisler:** çok boyutlu diziler ve matris hesaplama algoritmaları.
